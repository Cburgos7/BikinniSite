# Quick Task 260818-s63 — Summary

Prepared the Elegant Moments catalog images and built the Shopify push path.
Follows on from [260818-rxc](../260818-rxc-build-elegant-moments-to-shopify-product/).

## Key finding

The *Catalog Images – Download Links* PDF contains **only four collection ZIP
links**, not per-image URLs. Shopify's CSV importer fetches `Image Src` over HTTP,
so the CSV route cannot carry images at all. Changed approach: push products
through the GraphQL Admin API and stage the image bytes directly to Shopify's CDN.

## What was built

| File | Purpose |
|---|---|
| `prepare_images.py` | Recompress supplier JPEGs for upload |
| `push_products.py` | Create products + upload media via Admin API |
| `build_import.py` (edit) | Also emit `out/image_manifest.json` |
| `README.md` (edit) | Image and push procedures, renumbered gaps |

## Results

- **784 images** recompressed: 448 MB → **81 MB** (82% smaller), pixel dimensions
  unchanged at ~1200×1800. Licence forbids distorting proportions, so nothing was
  resized or cropped.
- **383 of 396 products** have images, averaging 2.1 each (front + back).
- One referenced file, `l1127_b.jpg`, is absent from the supplier ZIP. Its product
  keeps its front shot.
- Dry-run payload verified: correct options, variants, weights, barcodes, tags,
  `DRAFT` status, and the licence-required `Brand:` line and `Vendor`.

## Blocked

The push has **not been run** — it needs `SHOPIFY_CLIENT_ID` and
`SHOPIFY_CLIENT_SECRET` from the Dev Dashboard app to mint a token. No credentials
are stored in the repo.

Untested against the live API as a result. First run should be
`--limit 1` to confirm the staged-upload flow before the full 396.

Possible scope issue: the app's granted scopes are products, content, publications,
themes. If `stagedUploadsCreate` rejects for want of `write_files`, add that scope,
release a new app version, and re-approve the install (a new version alone does not
grant scopes).
